Q7 · 복수 선택 · 정답 1, 3

다음 중 옳은 것을 모두 고르시오.

  1. 1WHERE 절은 원하는 행만 남기는 필터이다
  2. 2SELECT에서 만든 별칭(ALIAS)을 WHERE에서 그대로 쓸 수 있다
  3. 3CONCAT 함수는 WHERE 절에서도 사용할 수 있다
  4. 4MySQL에서 emp_no 와 EMP_NO 는 서로 다른 컬럼이다
  5. 5SELECT * 는 실무에서 항상 권장된다
